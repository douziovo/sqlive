# 编辑器

## 功能

基于 Monaco Editor 的 SQL 编辑器，支持语法高亮、括号匹配、自动补全。编写 SQL 脚本后自动发送到后端执行。

## 执行流程

1. **输入**：编辑器内容变更后 100ms 防抖，触发自动执行
2. **发送**：完整脚本通过 POST /api/execute 发送到后端
3. **清库重跑**：后端接收脚本后，清空当前内存数据库的全部表，重新按语句拆分、逐条执行
4. **结果返回**：响应包含 tables（表名 + 列 + 行数据）、canonicalStatements（语句的起始/结束字符偏移）、error（可选）
5. **渲染**：前端更新表格视图、ER 图、语句高亮标注

## 错误处理

执行失败时，所有表保留上一次成功执行的状态。编辑器中的错误语句会被高亮标注，错误信息显示在编辑器底部的状态栏。点击「回滚」可恢复到 lastValidCode。

## SQL 解析器

编辑器依赖后端的 SqlParser 组件进行语句拆分（~280 行，无第三方解析库依赖）。它在字符层面逐字扫描：

- 跳过空白和注释时准确累加行号
- 追踪引号状态（单引号 '' / 双引号 ""），不对称处理转义规则
- 记录 BEGIN/END 深度和 CASE/END 深度，遇到 END 优先递减 caseDepth
- 每条语句输出 startPos 和 endPos（UTF-16 偏移，与 JavaScript String.substring 对齐）

解析器输出的偏移被前端用于语句高亮和元组定位（见数据可视化 - 内联编辑）。

## 快捷键

- Ctrl + Enter：手动触发执行
