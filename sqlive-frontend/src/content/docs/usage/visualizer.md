# 数据可视化

## 表格渲染

POST /api/execute 返回的 db.tables 包含当前库中所有表的结构和数据。前端将它们渲染为多个独立的表格组件：

- 列名显示在表头，数据类型以灰色标签标注
- 行数据按返回顺序平铺
- 表名下方显示行数和列数概览

列类型从 columnTypes 中提取原始 SQL 类型定义（如 VARCHAR(255) PRIMARY KEY），经 parsePrimaryType 简化为小写通用类型。

## 内联编辑

这是设计上最特殊的一个功能——在表格中改数据，系统会自动反向生成对应的 SQL。

**流程：**

1. 双击单元格进入编辑状态
2. 修改值后按 Enter 确认
3. useBidirectionalSync 拿到当前表的 INSERT 语句的字符偏移（来自后端的 canonicalStatements）
4. 解析出 VALUES 子句，按列顺序定位到对应元组和值位置
5. 替换值为新值（经 enforceTypeConstraints 做类型校验和转义）
6. 重新发送完整脚本到后端执行
7. 如果执行失败，lastValidCode 保留修改前的代码，编辑器回滚到改前状态

**约束：** 仅对当前查询结果中的值做替换，不生成 UPDATE/DELETE 语句。适合快速调整数据集、验证假设。

## 大数据量

当单表返回超过 1000 行时，后端自动限制返回行数，并在 truncation 信息中标记截断状态。截断后的表格底部会显示「仅显示前 N 行」提示。截断不影响数据库内的完整数据——缩小查询范围可获取完整结果。

## 导出

表格右上角提供 CSV 导出按钮，将当前表的数据以逗号分隔的格式导出，BOM 头部兼容 Excel 中文显示。导出内容只包含实际数据行，不含截断提示行。
